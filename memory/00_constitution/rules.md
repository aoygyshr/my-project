# 投資方針・運用ルール（投資憲章）

作戦本部（Claude Cowork）およびCEO（あなた）によって決定される基本方針です。

## 基本方針
- **投資対象**: 日本株（東証プライム・スタンダード・グロース）/ 米国株
- **投資スタイル**: 中長期成長株 / 高配当バリュー / スイングトレード（目的に応じて設定）
- **リスク許容度**: 1銘柄あたりの最大損失許容率（例: 損切り -7%〜-10%）

## 売買基準の目安
- **買いシグナル**:
  - 移動平均線（ゴールデンクロス）
  - RSI（売られすぎ水準からの反発）
  - 業績・上方修正などのカタリスト
- **売りシグナル**:
  - 目標株価到達（利益確定 +15%〜+20%）
  - 損切りライン到達
  - デッドクロス発生
