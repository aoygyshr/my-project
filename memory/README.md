# AI投資チーム 共有ハブ（チームの記憶）

ジョン・シュウギョウ著『生成AI投資の教科書［Antigravity/Claude Cowork編］』に基づく、AI投資チームの共有ストレージ（記憶）です。

## フォルダ構成
- `00_constitution/` : 投資憲章・基本ルール（作戦本部Claude Coworkが策定）
- `01_watchlist/`    : 監視対象銘柄リスト（発掘された注目株）
- `02_reports/`      : 分析レポート（現場エージェントAntigravityが作成）
- `03_signals/`      : 売買シグナル（買い時・売り時判定）
- `tools/`           : 現場エージェントが使用する分析・取得スクリプト
